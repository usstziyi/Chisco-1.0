# Chisco 与 Chisco-2.0 数据集链接

核对日期：2026-10-01。

两个数据集均有公开的 GitHub 数据集仓库。下方分别列出 OpenNeuro 的数据集仓库和作者的代码仓库；下载 EEG 数据可使用对应的 OpenNeuro 入口。固定版本链接保留原记录中的版本号。

## Chisco / Chinese Imagined Speech Corpus

数据集编号：`ds005170`。

原论文包含 3 名受试者，公开数据后来扩展到 5 名；提供原始 EDF 和 FIF、PKL 预处理数据。

### 数据集与代码

- [GitHub 数据集仓库：OpenNeuroDatasets/ds005170](https://github.com/OpenNeuroDatasets/ds005170)
- [GitHub 作者代码仓库：zhangzihan-is-good/Chisco](https://github.com/zhangzihan-is-good/Chisco)
- [OpenNeuro 数据集主页](https://openneuro.org/datasets/ds005170)
- [OpenNeuro 固定版本：1.1.2](https://openneuro.org/datasets/ds005170/versions/1.1.2)

### 论文

- [Chisco: An EEG-based BCI dataset for decoding of imagined speech（Scientific Data，2024）](https://www.nature.com/articles/s41597-024-04114-1)
- [论文全文（PMC）](https://pmc.ncbi.nlm.nih.gov/articles/PMC11582579/)

## Chisco-2.0 / COFETT（Corpus OF Eeg-To-Text）

数据集编号：`ds006317`。

OpenNeuro 的 Chisco-2.0 对应 COFETT 论文与代码；包含 2 名受试者的原始 EDF 数据，采用同一句子跨时段重复采集的设计。

### 数据集与代码

- [GitHub 数据集仓库：OpenNeuroDatasets/ds006317](https://github.com/OpenNeuroDatasets/ds006317)
- [GitHub 作者代码仓库：baoyudu/COFETT](https://github.com/baoyudu/COFETT)
- [OpenNeuro 数据集主页](https://openneuro.org/datasets/ds006317)
- [OpenNeuro 固定版本：1.1.1](https://openneuro.org/datasets/ds006317/versions/1.1.1)

### 论文

- [Is EEG-to-Text Feasible in Real-World Scenarios? An In-Depth Analysis Using a Neuropsychology-Inspired Benchmark（ACL，2026）](https://aclanthology.org/2026.acl-long.61/)
- [论文 PDF](https://aclanthology.org/2026.acl-long.61.pdf)
